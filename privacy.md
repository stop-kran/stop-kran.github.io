# Политика конфиденциальности приложения «Стоп-кран»

**Дата последнего обновления:** 2 сентября 2026 г.

## 1. Общие положения
Приложение **«Стоп-кран»** (далее — «Приложение») разработано для защиты пользователей от мошеннических действий при использовании мобильной связи и интернет-сервисов. Мы уважаем вашу приватность и обязуемся защищать любую информацию, которую Приложение обрабатывает.

**Важно:** Все данные обрабатываются и хранятся **исключительно локально** на вашем устройстве. Приложение не передаёт, не сохраняет на внешних серверах и не предоставляет третьим лицам никакую личную информацию.

## 2. Какие данные обрабатываются
Для выполнения своих функций Приложение запрашивает доступ к следующим данным:
- **SMS-сообщения** (чтение, получение, отправка) — для анализа входящих сообщений на предмет мошеннических признаков (ссылки, коды, просьбы перевести деньги и т.п.).
- **Состояние телефонного звонка** (READ_PHONE_STATE) — для определения момента звонка, номера вызывающего абонента и связи с подозрительными SMS/уведомлениями.
- **Уведомления других приложений** (доступ через NotificationListenerService) — для анализа текстов уведомлений из мессенджеров, банковских приложений и других источников на наличие мошеннического контента.
- **Содержимое экрана** (AccessibilityService) — для обнаружения ввода USSD-команд (например, переадресация вызова), которые могут быть использованы мошенниками.
- **Список доверенных номеров телефона** (вводится пользователем) — используется для отправки экстренных SMS-уведомлений при срабатывании тревоги.

## 3. Цели обработки
Все данные используются **исключительно** для:
- Обнаружения потенциально мошеннических сообщений, звонков и действий.
- Своевременного оповещения пользователя через звуковой, вибрационный и визуальный сигналы тревоги.
- Отправки предупредительного SMS на доверенные номера (по желанию пользователя) в случае тревоги.

## 4. Хранение и безопасность
- **SMS, уведомления, номера звонящих** анализируются в реальном времени и **не сохраняются** в постоянной памяти устройства. Временные данные (например, подозрительный текст) хранятся не более 5 минут и удаляются после срабатывания или сброса таймера.
- **Список доверенных номеров** сохраняется в локальном хранилище устройства (SharedPreferences), доступном только Приложению. Хранение осуществляется без дополнительного шифрования, но данные не передаются за пределы устройства.
- **Журнал событий** (LogStorage) содержит записи о тревогах и действиях Приложения. Хранится локально, ограничен 50 записями, старые записи автоматически удаляются через 30 дней.
- **Никакие данные не передаются по сети**, не синхронизируются с облаком и не доступны разработчику или третьим лицам.

## 5. Разрешения, запрашиваемые Приложением
Приложение запрашивает следующие разрешения:
- `READ_SMS` — для чтения входящих SMS.
- `RECEIVE_SMS` — для приёма SMS.
- `SEND_SMS` — для отправки экстренных уведомлений на доверенные номера.
- `READ_PHONE_STATE` — для мониторинга звонков.
- `SYSTEM_ALERT_WINDOW` — для отображения тревожного окна поверх всех приложений.
- `RECEIVE_BOOT_COMPLETED` — для автоматического запуска после перезагрузки устройства.
- `VIBRATE` — для вибрации при тревоге.
- `POST_NOTIFICATIONS` (Android 13+) — для отображения уведомления о работе фонового сервиса.
- `MANAGE_OWN_CALLS` — для управления вызовами (используется для определения состояния звонка).
- `USE_FULL_SCREEN_INTENT` — для полноэкранного отображения тревоги.
- `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_PHONE_CALL` — для фоновой работы сервиса.

Все разрешения необходимы исключительно для выполнения основной функции Приложения — защиты от мошенничества.

Приложение предоставляется «как есть». Мы не гарантируем 100% обнаружение всех мошеннических попыток, однако прилагаем все усилия для повышения точности. Пользователь несёт ответственность за собственные решения и действия, принимаемые на основе информации, предоставленной Приложением.

Приложение может отправлять экстренные SMS на доверенные номера, указанные пользователем. Отправка осуществляется через оператора сотовой связи и тарифицируется согласно тарифному плану пользователя. Разработчик не несёт ответственности за любые финансовые расходы, связанные с отправкой SMS, включая списание денежных средств со счёта мобильного телефона.
