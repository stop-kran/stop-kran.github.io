Этот репозиторий содержит официальные юридические документы для мобильного приложения **«Стоп-кран»** (Stop Kran) — инструмента для защиты от телефонного мошенничества и фишинга.

- [Политика конфиденциальности](privacy.md) — описывает, какие данные обрабатываются, как и с какой целью.

## О приложении

«Стоп-кран» — это антимошенническое приложение, которое в реальном времени анализирует входящие SMS, уведомления и телефонные звонки. При обнаружении подозрительных признаков (просьба сообщить код, ссылки на фишинговые сайты, USSD-команды и т.п.) срабатывает звуковая и визуальная тревога.

- Все данные обрабатываются **локально на устройстве** и никогда не передаются через интернет.
- Приложение не передаёт личную информацию через интернет и не сохраняет её на внешних серверах. Все данные, включая доверенные номера и журнал событий, хранятся исключительно локально на устройстве пользователя.
- При обнаружении угрозы приложение может отправить экстренное SMS на заранее указанные пользователем доверенные номера, если данная опция увлючена (по умолчанию -ДА).
- **Важно:** Отправка SMS осуществляется через вашего мобильного оператора и может тарифицироваться согласно вашему тарифному плану. Разработчик не несёт ответственности за любые финансовые расходы, связанные с отправкой SMS-сообщений, включая списание денежных средств со счёта вашего мобильного телефона. Подробнее см. в Пользовательском соглашении.
